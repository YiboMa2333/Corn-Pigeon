# DESIGN.md — 疯狂的鸽子

## 气质与意象
- **核心意象**：夏日午后阳光农场，一只圆滚滚的灰白色胖鸽子围着金黄玉米棒打转偷吃，像个贪心又滑稽的小偷。抖音小游戏的"魔性 + 可爱"气质，节奏明快、反馈密集。
- **关键词**：明亮、活泼、魔性、卡通、田园、贪吃。
- **画面叙述**：蓝天白云缓缓飘动，绿色草地带着轻微视差，画面中央一根黄绿色玉米棒缓缓自转，胖鸽子扑棱着小翅膀绕圈，眼睛直勾勾盯着玉米粒。

## 视觉策略
- 游戏主体（鸽子、玉米、粒子、背景）全部用 **Canvas 2D** 程序化绘制，零外部图片资源。
- UI 层（分数、时间、Combo、开始/结束弹窗、按钮）使用 **DOM + CSS** 覆盖在 Canvas 上。
- 卡通造型：所有角色使用圆润形状、无尖锐角，粗描边 + 柔和渐变 + 高光。
- 背景分层视差：天空渐变 → 远云（慢）→ 近云（中）→ 草地（快），营造纵深感。

## 字体排版
- 中文卡通字体：`ZCOOL KuaiLe`（Google Fonts，通过 fonts.googleapis.cn 加载）
- 数字/英文：`Baloo 2`（圆润粗体）
- 标题：60px+ 超大号，渐变填充 + 棕色 4px 描边 + 投影，带持续弹跳动画。
- 分数：48px 粗体数字，白字棕边，得分时 scale 弹跳。
- 按钮：圆角胶囊形，24px 粗体字，悬停放大、按下压缩。

## 动效与交互
- **鸽子扇翅**：翅膀以 12Hz 上下扇动（冲刺时加快到 20Hz），身体随扇翅轻微上下浮动。
- **环绕飞行**：鸽子沿椭圆轨道绕玉米飞行，始终面朝玉米（根据位置自动水平翻转）。
- **冲刺啄击**：0.3 秒三段式——0.1s ease-out 冲向玉米 → 0.05s 啄击挤压（身体压扁 15%）→ 0.15s ease-in-out 返回轨道。
- **方向切换**：每 15 秒切换顺时针/逆时针，切换时屏幕边缘闪过一道弧形光带，鸽子翻转并眨眼。
- **粒子飞溅**：啄中后 12-16 颗玉米粒形粒子向四周放射，带重力下落和旋转，好玉米金色、坏玉米暗色，0.6s 淡出。
- **Combo 火焰**：Combo≥3 时鸽子身后拖出橙红火焰粒子，Combo 越高火焰越旺。
- **分数飘字**：从啄击位置升起 `+10`/`-15`/`+5 BONUS`，0.8s 上飘 + 淡出 + 轻微缩放。
- **背景视差**：云朵以 8-20px/s 缓慢横移循环。
- **按钮**：cubic-bezier(0.34, 1.56, 0.64, 1) 弹性缓动。

## 设计禁忌
- 不要写实风格、照片纹理、3D 透视。
- 不要暗色主题或冷灰基调。
- 不要锐利边角或细线描边（描边至少 3px）。
- 不要依赖外部图片/音频资源（全部代码生成）。
- 不要在 Canvas 里绘制 UI 文字（UI 一律走 DOM 保证清晰度）。
- 不要让玉米棒旋转速度超过玩家可反应范围（最高约 2 圈/秒）。
